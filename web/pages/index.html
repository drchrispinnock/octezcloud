Bake on Tezos from your own cloud account, with the key in a TEE.

Octez Cloud generates a template that deploys an Octez node, DAL node and baker into your AWS account. Azure and GCP come later. The consensus key is generated and used only inside a hardware-backed trusted execution environment, and is sealed to a key that only the attested signer image can unlock.

Configure a deployment Read the threat model

No credentials, no backend

This is a static site. You deploy the template yourself through your cloud's own console. We never see your account, your keys or your funds.

Key in a TEE

The tz4 consensus key lives in a Nitro Enclave. KMS releases the sealing key only to the exact image measurement pinned in your key policy.

Verify it yourself

Images are built reproducibly, and the measurements are published with each release. You can check the attestation your deployment produces in your browser.
